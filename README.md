# EGC Admin Tools — source-прототип

Незалежний початковий модуль для інтеграції з наданим EGC. **Повний мод за ТЗ ще не готовий; компіляцію й перевірку в грі не виконано.**

Створено: аудит чотирьох архівів, власну архітектуру, сім нових Enfusion-скриптів, окремий UI/input, серверні перевірки, read-only EGC ban/VIP інтеграції, online roster/досьє, Heal/Kick та audit. Оригінальні EGC і архіви збережено без змін, SHA-256 перевірено. Чужі скрипти/UI/текстури до mod не включено.

Не реалізовано: Ban/Unban, VIP-write/expiry, teleport/bring/goto, God/Revive/Spectator/невидимість, server/match info та announcements. Для інтеграцій запису потрібне погодження контрактів; для завершення — Workbench і runtime-тести.

Критичне знаходження: вихідний EGC може потрапити в нескінченний цикл при перевірці security.bin. Деталі та пропозиція без застосування — документ 04.

`mod/` — лише новий код. `research/` — незмінні дослідницькі копії, не встановлювати та не включати до нового addon. `docs/archive_manifest.json` — повний індекс усіх вихідних файлів і класів; `docs/EGC_INDEX.md` — індекс усіх 84 EGC-скриптів.

Фактична перевірка: 68 статичних контрактів/symbol checks, 0 провалів. Це не компіляція, не перевірка RPC transport і не ігрові тести. Наданий snapshot API не містить достатнього доказу номера game build; сумісність із встановленою 1.9 ще треба підтвердити.
